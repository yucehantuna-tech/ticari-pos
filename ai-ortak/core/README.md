# Ticaret Motoru

Bağımsız, test edilebilir çekirdek.

- economics: gerçek birim ekonomi hesabı
- product-hunter: ürünleri filtreleme ve sıralama
- permissions: işlem yetkileri ve kullanıcı onayı
- connectors: pazar yeri/tedarikçi/kargo vb. standart yetenek sözleşmesi
- audit: tüm kritik işlemler için kayıt modeli

Bu katman gerçek servislerle bağlanmadan önce güvenli bir simülasyon/motor olarak kullanılabilir.
